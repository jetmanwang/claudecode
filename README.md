# Java猜数字游戏

这是一个适合Java初学者的简单猜数字游戏项目。

## 游戏说明

- 程序会随机生成一个1到100之间的数字
- 玩家输入猜测的数字
- 程序会提示"太大了"或"太小了"
- 猜中后会显示总共猜了多少次
- 可以选择再玩一次

## 如何编译和运行

### 方法1：使用命令行

1. 编译程序：
```bash
javac src/GuessingGame.java
```

2. 运行程序：
```bash
java -cp src GuessingGame
```

### 方法2：直接编译运行（一步到位）

```bash
cd src
javac GuessingGame.java
java GuessingGame
```

## 代码知识点

这个游戏使用了以下Java基础知识：

1. **变量声明**：int、boolean、String类型
2. **Scanner类**：读取用户输入
3. **Random类**：生成随机数
4. **if-else语句**：条件判断
5. **while循环**：重复执行代码
6. **逻辑运算符**：&&、||、!等
